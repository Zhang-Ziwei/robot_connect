# robot_connect 命令接口一览

> 调度入口：`POST http://<主机>:8090/`（端口见 `robot_config.json` → `http_server.port`）  
> 回调出口：`POST <callback.url>`（robot_connect 主动推送，默认测试 `http://127.0.0.1:8099/callback`）  
> 测试样例：`test_commands/` 目录  
> 回调测试：`python3 tools/callback_server.py --port 8099`

---

## 1. 通用约定

### 1.1 HTTP 调度请求（外部 → robot_connect）

```json
{
  "header": { "seq": 1, "stamp": { "secs": 0, "nsecs": 0 }, "frame_id": "map" },
  "cmd_id": "唯一命令ID",
  "cmd_type": "命令类型",
  "params": { },
  "extra": { }
}
```

`header` / `extra` 可选。也支持封装格式：`{"params":{}, "data":{"cmd_type":"...", "cmd_id":"..."}}`。

### 1.2 HTTP 调度响应（robot_connect → 外部）

**成功（通用）**

```json
{
  "success": true,
  "code": 0,
  "message": "操作成功",
  "cmd_id": "与请求一致"
}
```

**失败（通用）**

```json
{
  "success": false,
  "code": 2003,
  "message": "错误描述",
  "cmd_id": "与请求一致"
}
```

**WAIC 异步受理**（立即返回，后台执行）

```json
{
  "success": true,
  "code": 0,
  "action_type": "PICK_BOX_TO_SP",
  "description": "",
  "message": "动作 PICK_BOX_TO_SP 已受理，后台执行中"
}
```

### 1.3 任务完成回调（robot_connect → 外部，需配置 `callback.enabled=true`）

**请求（CallbackSender POST）**

```json
{
  "cmd_id": "PICK_BOX_TO_SP_001",
  "cmd_type": "PICK_BOX_TO_SP",
  "success": true,
  "message": "搬运完成: point2 → point3"
}
```

**响应（接收方须确认）**

```json
{ "received": true }
```

未在 `timeout` 内收到 `received:true`，将间隔 `retry_interval` 秒重发，最多 `retry` 次。

## 2. 全项目公共命令（任意 active_project 均可用）

> 注册于 `handlers/dispatcher_base.py`。除白名单外，须先 `START_WORKING`。

| cmd_type | 功能 | 休眠白名单 |
|---|---|---|
| `START_WORKING` | 激活系统 | ✓ |
| `RESET_SYSTEM` | 重置到休眠 | ✓ |
| `GET_TASK_STATE` | 查询任务状态 | ✓ |
| `ROBOT_ACTION` | 机器人单独动作 | |
| `GET_UPPER_LIMB_JOINT_STATES` | 上肢关节 | |
| `GET_HAND_JOINT_STATES` | 手部关节 | |
| `GET_FINGER_PRESSURES` | 手指压力 | |
| `GET_FULL_BODY_SENSOR_STATES` | 全身传感器聚合 | |
| `GET_ROBOT_MOTION_STATE` | 里程计/位姿 | |
| `GET_BATTERY_STATE` | 电池电量 | |

### START_WORKING

**请求**

```json
{ "cmd_id": "START_WORKING_001", "cmd_type": "START_WORKING", "params": {} }
```

**响应**

```json
{ "success": true, "message": "已接收START_WORKING命令，程序开始工作", "cmd_id": "START_WORKING_001", "code": 0 }
```

### RESET_SYSTEM

**请求**

```json
{ "cmd_id": "RESET_001", "cmd_type": "RESET_SYSTEM", "params": {} }
```

**响应**

```json
{ "success": true, "message": "系统已重置到休眠状态，配置文件已重新加载，发送START_WORKING命令可重新激活", "code": 0 }
```

### GET_TASK_STATE

**请求**

```json
{
  "cmd_id": "GET_TASK_STATE_001",
  "cmd_type": "GET_TASK_STATE",
  "params": { "target_cmd_id": "PICK_BOX_TO_SP_001" }
}
```

`target_cmd_id` 省略时查当前任务。

**响应（成功）**

```json
{
  "success": true,
  "code": 0,
  "message": "状态查询成功",
  "data": {
    "task_id": "PICK_BOX_TO_SP_001",
    "robot_id": "robot_a",
    "status": "RUNNING",
    "current_step": { "label": "NAVIGATING", "detail": "导航到 point2" },
    "error_message": null,
    "duration_seconds": 12.5
  }
}
```

`status` 常见值：`IDLE` / `RUNNING` / `COMPLETED` / `ERROR`。

### ROBOT_ACTION

**请求**

```json
  "cmd_id": "robot_action_001",

```

**响应（成功）**

```json

```

## 7. KAIAO 项目命令（`active_project`: KAIAO / ALL）

| cmd_type | 功能 | HTTP 响应 | 完成后回调 |
|---|---|---|---|
| `PICK_BOX_TO_SP` | 按货架格取箱并搬至目标点 | 立即受理 | ✓ |
| `PICK_COMPONENT_TO_SP` | 分拣指定数量零件至目标点 | 立即受理 | ✓ |
| `PICK_UP_BOX` | 单步抓箱 | 立即受理 | ✓ |
| `PUT_DOWN_BOX` | 单步放箱 | 立即受理 | ✓ |
| `NAVIGATION` | 纯导航 | 立即受理 | ✓ |

### PICK_BOX_TO_SP

**请求** → `test_commands/KAIAO_PICK_BOX_TO_SP_command.json`

```json
{
  "cmd_id": "PICK_BOX_TO_SP_001",
  "cmd_type": "PICK_BOX_TO_SP",
  "params": {
    "robot_id": "robot_a",
    "box_initial_area": {
      "shelf_num": [0, 1, 2],
      "shelf_type": "shelf"
    },
    "box_target_area": {
      "shelf_num": [0, 1, 0],
      "shelf_type": "agv_car"
    }
  }
}
```

`box_initial_area` / `box_target_area` 为对象：`shelf_type`（`shelf` / `agv_car`）+
`shelf_num` `[货架编号, row, column]`。`active_project=KAIAO_FLOW` 时由流程图
「等待外部命令」收下整包 params，再用「解析取放位置」算出导航点名；
原生 `KAIAO` 仍在 Python 里解析。详见 `programs/KAIAO_FLOW/README.md`。

### PICK_COMPONENT_TO_SP

**请求** → `test_commands/KAIAO_PICK_COMPONENT_TO_SP_command.json`

```json
{
  "cmd_id": "PICK_COMPONENT_TO_SP_001",
  "cmd_type": "PICK_COMPONENT_TO_SP",
  "params": [
    {
      "box_initial_area": "component_car",
      "box_num": 0,
      "component_type": "black_screw",
      "target": [
        { "box_target_area": [0, 0, 0], "component_number": 10 },
        { "box_target_area": [0, 1, 0], "component_number": 10 }
      ]
    }
  ]
}
```

`box_num`：闪攀小车前左箱 `0` / 右箱 `1`。零件类型含 `black_screw`、`black_tube`、`black_square`、`black_joystick`、`black_fan`、`yellow_hinge`、`white_connector`、`wire_harness`。多个播种墙目的地用 `target` 列表。每件循环：小车抓取 → 导航至播种墙 → 放下（`number` 固定为 1）。旧版 `params` 为单个对象仍可用。

### ROS 任务参数（相对 WAIC 的扩展）

| task | area | extra_params |
|---|---|---|
| `pick_up_box` | `agv_car` / `shelf` | `shelf_level`（0–3） |
| `pick_up_heavy_box` | **仅 `shelf`** | 同 `pick_up_box`；货架箱累计重量 ≥ `kaiao_component.heavy_box_threshold_kg`（默认 0.8kg） |
| `put_down_box` | `agv_car` / `shelf` | `shelf_level`（0–3） |
| `put_down_heavy_box` | `agv_car` / `shelf` | 同 `put_down_box`；与本次 `pick_up_heavy_box` 成对 |
| `adjust_pose` | 与放箱 area 相同 | `shelf_level` 与放箱相同；离架后退中间点（同层也会发） |
| `pick_up_component` | `component_car` | `type`, `number: 1`, `box_num`（0/1） |
| `put_down_component` | `shelf` | `shelf_level`, `type`, `number: 1` |

单步 `PICK_UP_BOX` / `PUT_DOWN_BOX` 可在 `params` 中附加 `robot_area`、`shelf_level`。

## 8. 回调测试工具

```bash
# 正常确认
python3 tools/callback_server.py --port 8099

# 模拟前 2 次不确认，测试重发
python3 tools/callback_server.py --port 8099 --fail-count 2

# 模拟处理慢（超过 callback.timeout 将触发超时重发）
python3 tools/callback_server.py --port 8099 --delay 15
```

`robot_config.json` 配置示例：

```json
"callback": {
  "enabled": true,
  "url": "http://127.0.0.1:8099/callback",
  "timeout": 10,
  "retry": 3,
  "retry_interval": 10
}
```

## 9. 命令注册与项目切换

命令在 `programs/TJSH/cmd_handler.py` 按 `active_project` 注册：

| active_project | 可用命令 |
|---|---|
| `TJSH` | 公共 + TJSH |
| `ATC` | 公共 + ATC |
| `AJL` | 公共 + AJL（含 `AJL_*` 前缀） |
| `WAIC` | 公共 + WAIC |
| `KAIAO` | 公共 + KAIAO |
| `ALL` | 全部（AJL 流程控制须用 `AJL_PROCESS_*` 前缀；WAIC/KAIAO 同名命令以最后注册为准） |

未知 `cmd_type` 响应：

```json
{ "success": false, "code": 1001, "message": "未知的命令类型: XXX" }
```

系统休眠时拦截：

```json
{ "success": false, "code": 2001, "message": "系统休眠中，请先发送 START_WORKING 命令启动系统" }
```
