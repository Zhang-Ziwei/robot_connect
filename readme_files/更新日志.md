# 更新日志

本机与 GitHub 共用这一份版本记录（从 **3.0.2** 起）。  
当前版本见仓库根目录 `VERSION`。历史功能说明仍在同目录的 `新功能清单.md`，本文件只记版本迭代。

## 3.0.3 — 2026-09-10

### CONST_FLOW

- 装表编排从 Python 整块封装拆到三张子流程图：`const_install_station` / `const_install_once` / `const_uninstall_once`；主图仍是一个块，双击可进子流程改顺序和重插次数
- 机器人装表/拆表/导航改用通用功能块；MQTT 让位、合龙、识别结果等仍用 ConST 专有节点
- 子流程用 `role: "subflow"` 标记，不参与「只能激活一份入口流程」；保存时补回 `id`/`name` 等元信息，避免子流程被误当成第二入口
- 表掉落不再算动作失败，图上分支转呼人工；重插前拆表补齐上位机让位/合龙
- 检定系统 MQTT 与可选 PLC 分开：无独立 Modbus 时可关 `plc.enabled`

### KAIAO / KAIAO_FLOW

- 走廊中间点：近 AGV 货架格（`shelf0_3` / `shelf1_3`）持箱去 agv_car 时，后退并校正后再远离货架平移，避免转 90° 撞架
- 货架互搬：有箱则后退 → 转向零件车 → 目标正前方 → 转向进入；空手则后退后直达
- 上述参数可在图形化「运行控制 → 配置文件」里按字段注释修改，与点位写在同一份 KAIAO `robot_config.json`

### 流程引擎与编辑器

- 并行节点支持在汇合点汇齐后再继续；演练可取消
- 流程图中文 id、激活开关、子流程下拉与「打开子流程」；`set_variable` 支持加减
- 信号别名（如 `manual_reset` ≡ `MANUAL_RESET_COMPLETED`）
- 机器人 WebSocket 重连补上 rosbridge 子协议，避免 mock 上 HTTP 400 刷屏

### WRC_FLOW

- `simple_line` 现场装配流程调整

## 3.0.2 — 2026-09-08

### 2026-09-08

- 流程编辑器增加交互式「使用说明」：线框引导从建图、拖功能块，到演练和运行控制（新手用 Mock 代替真机）
- 增加流程输出 / 导入：可导出当前图或本项目全部流程，软件更新后迁回
- 工具栏顺序改为：激活、新建、输出、保存 | 校验、演练、点位、运行控制…

### 2026-09-07

- 新增 `CONST_FLOW`：康斯特压力表全自动检定（MQTT 对接检定系统，图形化主流程；`START_WORKING` 后按配置自动开跑）
- 通用 MQTT 客户端；Docker 镜像加入 `paho-mqtt`
- 命令状态查询带上当前 `active_project`；系统复位时可靠断开机器人
- mock rosbridge 与流程演练联调修复
- WRC 主流程 / `simple_line` 现场图调整
