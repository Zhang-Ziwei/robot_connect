# 错误码参考手册

> 本文档列出 robot_connect 所有 HTTP API 的业务错误码，用于接口对接、调试排查和日志分析。  
> 源码定义：`infrastructure/constants.py` → `class ErrorCode`

---

## 响应结构

所有接口响应统一格式：

```json
{
  "success": false,
  "code":    2003,
  "message": "机器人正忙",
  "cmd_id":  "PICK_BOX_TO_SP_001"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `success` | bool | `true` 表示成功，`false` 表示失败 |
| `code` | int | 业务错误码（成功时为 `0`）|
| `message` | string | 可读描述，失败时包含具体原因 |
| `cmd_id` | string | 原始命令 ID（部分接口返回）|

---

## 错误码分段规则

| 段 | 范围 | 类别 |
|---|---|---|
| 成功 | `0` | 操作成功 |
| 1xxx | 1001–1004 | 请求格式错误 |
| 2xxx | 2001–2010 | 机器人相关错误 |
| 3xxx | 3001–3007 | 任务相关错误 |
| 4xxx | 4001–4006 | 系统错误 |
| 5xxx | 5001–5003 | 资源错误 |

---

## 0 — 成功

| 错误码 | 常量名 | HTTP 状态 | 描述 |
|---|---|---|---|
| `0` | `SUCCESS` | 200 | 操作成功 |

---

## 1xxx — 请求格式错误

请求体本身有问题，通常由调用方修复。

| 错误码 | 常量名 | HTTP 状态 | 描述 | 常见原因 |
|---|---|---|---|---|
| `1001` | `INVALID_JSON` | 400 | JSON 格式错误 | 请求体不是合法 JSON |
| `1002` | `MISSING_PARAMS` | 400 | 缺少必要参数 | `params` 中必填字段为空 |
| `1003` | `INVALID_PARAMS` | 400 | 参数格式错误 | 字段类型不匹配、值越界 |
| `1004` | `UNKNOWN_CMD_TYPE` | 400 | 未知命令类型 | `cmd_type` 未在当前项目中注册 |

---

## 2xxx — 机器人相关错误

| 错误码 | 常量名 | HTTP 状态 | 描述 | 常见原因 / 处理建议 |
|---|---|---|---|---|
| `2001` | `ROBOT_NOT_FOUND` | 404 | 机器人不存在 | `robot_id` 不在配置中，检查 `robot_config.json` |
| `2002` | `ROBOT_NOT_CONNECTED` | 503 | 机器人未连接 | ROS Bridge 连接断开，等待重连或检查网络 |
| `2003` | `ROBOT_BUSY` | 409 | 机器人正忙 | 上一个任务尚未完成，等待后重试；或发送 `RESET_SYSTEM` 复位 |
| `2004` | `ROBOT_ACTION_DISABLED` | 503 | 机器人动作接口未启用 | `constants.py` 中 `ENABLE_ROBOT_B_ACTIONS=False` |
| `2005` | `ROBOT_ACTION_FAILED` | 500 | 机器人动作执行失败 | 机械臂/底盘动作返回失败，查看机器人日志 |
| `2006` | `ROBOT_SERVICE_ERROR` | 502 | 机器人 ROS 服务调用失败 | ROS 服务超时或返回错误 |
| `2007` | `ROBOT_BATTERY_INFO_PENDING` | 503 | 电量信息未获取 | 系统启动后尚未收到电池 topic，稍等后重试 |
| `2008` | `ROBOT_LOW_BATTERY` | 503 | 机器人低电量 | 电量低于阈值，正在自动充电，充电完成后自动恢复 |
| `2009` | `ROBOT_CHARGING_REJECT_TASK` | 503 | 充电中，电量不足以接收任务 | 等待充电至可接收任务阈值（默认 50%）|
| `2010` | `ROBOT_CHARGING_FAILED` | 500 | 机器人充电失败 | 导航到充电桩失败或充电状态异常 |

---

## 3xxx — 任务相关错误

| 错误码 | 常量名 | HTTP 状态 | 描述 | 常见原因 / 处理建议 |
|---|---|---|---|---|
| `3001` | `TASK_NOT_FOUND` | 404 | 任务不存在 | `GET_TASK_STATE` 查询的 `target_cmd_id` 与当前任务不匹配；任务已完成后状态机已被重置 |
| `3002` | `TASK_ID_MISMATCH` | 404 | 任务 ID 不匹配 | 查询 ID 与正在执行的任务 ID 不一致 |
| `3003` | `TASK_QUEUE_DISABLED` | 503 | 任务队列未启用 | 当前系统运行在同步模式，不支持队列接口 |
| `3004` | `TASK_TIMEOUT` | 408 | 任务超时 | 动作或导航在规定时间内未完成 |
| `3005` | `TASK_CANCELLED` | 410 | 任务已取消 | 任务被 `RESET_SYSTEM` 主动取消 |
| `3006` | `TASK_FAILED` | 500 | 任务执行失败 | 机器人子步骤失败，见 `message` 字段具体原因 |
| `3007` | `TASK_NOT_STARTED` | 409 | 流程尚未启动 | 需要先发送 `START_WORKING` 或 `PROCESS_BEGINS` 激活系统 |

---

## 4xxx — 系统错误

| 错误码 | 常量名 | HTTP 状态 | 描述 | 常见原因 / 处理建议 |
|---|---|---|---|---|
| `4001` | `HANDLER_NOT_INIT` | 503 | 命令处理器未初始化 | 系统启动中，稍后重试 |
| `4002` | `SYSTEM_RESET_FAILED` | 500 | 系统重置失败 | `RESET_SYSTEM` 执行时内部异常，查看错误日志 |
| `4003` | `CMD_EXECUTION_ERROR` | 500 | 命令执行异常 | handler 内部未捕获异常，查看服务端日志 |
| `4004` | `INTERNAL_ERROR` | 500 | 内部错误 | 通用系统错误，查看 `logs/` 目录下错误日志 |
| `4005` | `SYSTEM_SLEEPING` | 409 | 系统休眠中 | 尚未发送 `START_WORKING`，需先激活系统 |
| `4006` | `SYSTEM_ACTIVATING` | 503 | 系统激活中 | 已收到 `START_WORKING`，正在连接机器人/下发地图，稍后再试 |

---

## 5xxx — 资源错误

| 错误码 | 常量名 | HTTP 状态 | 描述 | 常见原因 / 处理建议 |
|---|---|---|---|---|
| `5001` | `RESOURCE_INSUFFICIENT` | 422 | 资源不足 | 瓶子数量不足、耗材不足等 |
| `5002` | `STORAGE_FULL` | 422 | 存储区已满 | 后部暂存区槽位已占满，需先清空 |
| `5003` | `RESOURCE_NOT_FOUND` | 404 | 资源未找到 | 指定 ID 的瓶子或物料不存在 |

---

## HTTP 状态码速查

| HTTP 状态码 | 含义 | 对应错误码段 |
|---|---|---|
| `200` | 成功 | `0` |
| `400` | 请求格式错误 | `1001`–`1004` |
| `404` | 资源未找到 | `2001`, `3001`, `3002`, `5003` |
| `408` | 请求超时 | `3004` |
| `409` | 冲突（忙/未激活）| `2003`, `3007`, `4005` |
| `410` | 资源已消失（任务已取消）| `3005` |
| `422` | 请求合法但无法处理 | `5001`, `5002` |
| `500` | 服务器内部错误 | `2005`, `2010`, `3006`, `4002`–`4004` |
| `502` | 上游服务错误 | `2006` |
| `503` | 服务不可用 | `2002`, `2004`, `2007`–`2009`, `3003`, `4001`, `4006` |

## 快速排查指引

### 系统刚启动收到 4005
尚未激活，发送 `START_WORKING`：
```bash
curl -X POST http://localhost:8090 \
  -H "Content-Type: application/json" \
  -d '{"cmd_type": "START_WORKING", "cmd_id": "start_001", "params": {}}'
```

### 已发 START_WORKING 但收到 4006
系统正在连接机器人或下发导航地图，等待激活完成（日志出现「系统已激活」）后再发业务命令。

### 收到 3007（流程未启动）
需先发送对应项目的流程开始命令（如 ATC/AJL 的 `PROCESS_BEGINS`）。

### 收到 2003（机器人正忙）
1. 用 `GET_TASK_STATE` 查询当前任务进度
2. 若任务已异常卡住，发送 `RESET_SYSTEM` 强制复位

### 收到 3001（任务不存在）
`GET_TASK_STATE` 查询时 `target_cmd_id` 必须与发送任务时的 `cmd_id` 完全一致：
```json
{
  "cmd_type": "GET_TASK_STATE",
  "cmd_id": "query_001",
  "params": { "target_cmd_id": "PICK_BOX_TO_SP_001" }
}
```

### 收到 2002（机器人未连接）
检查 ROS Bridge 是否运行：
```bash
# 查看机器人 WebSocket 连接日志
docker logs <container> 2>&1 | grep "ROS Bridge\|rosbridge\|连接"
```

### 收到 5xxx（资源错误）
发送 `RESET_SYSTEM` 重置存储状态，或检查 `storage_state.json` 手动清理。
