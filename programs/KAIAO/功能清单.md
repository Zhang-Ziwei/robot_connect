# KAIAO 项目功能清单

> 货架/零件搬运中间件，HTTP 异步 + 回调，ROS 任务通过 `/robot_task` 下发。

---

## HTTP 命令

| cmd_type | 类型 | 说明 |
|---|---|---|
| `PICK_BOX_TO_SP` | 异步 | 从 `box_initial_area` 取箱，搬至 `box_target_area` |
| `PICK_COMPONENT_TO_SP` | 异步 | 从 `box_initial_area` 取件，按 `target` 分拣至播种墙 |
| `PICK_UP_BOX` | 异步 | 单步抓箱 |
| `PUT_DOWN_BOX` | 异步 | 单步放箱 |
| `NAVIGATION` | 异步 | 导航至 `area` |

### PICK_BOX_TO_SP

```json
{
  "cmd_type": "PICK_BOX_TO_SP",
  "params": {
    "box_initial_area": {
      "shelf_num": [0, 0, 0],
      "shelf_type": "agv_car"
    },
    "box_target_area": {
      "shelf_num": [0, 0, 0],
      "shelf_type": "shelf"
    }
  }
}
```

- `shelf_type`：ROS `area`，并参与导航点命名（`agv_car` / `shelf`）
- `shelf_num`：`[货架编号, row, column]` → 导航点 `{shelf_type}{编号}_{column}`（如 `agv_car0_0`），`row` → `shelf_level`（垂直层 0–3）
- 目前一次任务搬一只箱；多箱可后续扩展为列表

### PICK_COMPONENT_TO_SP

```json
{
  "cmd_type": "PICK_COMPONENT_TO_SP",
  "params": {
    "box_initial_area": "point1",
    "component_type": "black_screw",
    "target": {
      "box_target_area": [0, 0, 0],
      "component_number": 10
    }
  }
}
```

零件类型：`black_screw`、`black_tube`、`black_square`、`black_joystick`、`black_fan`。

`box_target_area` 为 `[货架编号, row, column]`：`编号 + column` → 放件导航点 `shelf{编号}_{column}`；`row` → 放置层 `shelf_level`。

多个播种墙目的地：`target` 直接传对象列表（或用 `targets` 字段，等价）。
