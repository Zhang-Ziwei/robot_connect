# KAIAO 项目功能清单

> 货架/零件搬运中间件，HTTP 异步 + 回调，ROS 任务通过 `/robot_task` 下发。
>
> 图形化编排版见 **[programs/KAIAO_FLOW/README.md](../KAIAO_FLOW/README.md)**（`active_project=KAIAO_FLOW`）。
> `PICK_BOX_TO_SP` / `PICK_COMPONENT_TO_SP` 在 FLOW 里由流程图编排；原生 KAIAO 仍保留本文件对应处理器。

---

## HTTP 命令

| cmd_type | 类型 | 说明 |
|---|---|---|
| `PICK_BOX_TO_SP` | 异步 | 从 `box_initial_area` 取箱，搬至 `box_target_area` |
| `PICK_COMPONENT_TO_SP` | 异步 | 从 `box_initial_area` 取件，按 `target` 分拣至播种墙 |
| `PICK_UP_BOX` | 异步 | 单步抓箱 |
| `PUT_DOWN_BOX` | 异步 | 单步放箱 |
| `NAVIGATION` | 异步 | 导航至 `area` |

### PICK_BOX_TO_SP

```json
{
  "cmd_type": "PICK_BOX_TO_SP",
  "params": {
    "box_initial_area": {
      "shelf_num": [0, 0, 0],
      "shelf_type": "agv_car"
    },
    "box_target_area": {
      "shelf_num": [0, 0, 0],
      "shelf_type": "shelf"
    }
  }
}
```

- `shelf_type`：ROS `area`，并参与导航点命名（`agv_car` / `shelf`）
- `shelf_num`：`[货架编号, row, column]` → 导航点 `{shelf_type}{编号}_{column}`（如 `agv_car0_0`），`row` → `shelf_level`（垂直层 0–3）
- 目前一次任务搬一只箱；多箱可后续扩展为列表
- 从 **货架** 取箱：按该格累计零件重量，达到 `kaiao_component.heavy_box_threshold_kg`（默认 0.8kg）时 ROS 任务为 `pick_up_heavy_box`（`area` 只能是 `shelf`），随后放箱必须成对调用 `put_down_heavy_box`。从 AGV 取箱重量视为 0，始终 `pick_up_box` + `put_down_box`。
- 抓箱成功后导航去放箱位：到达离架后退中间点时调用 `adjust_pose`（`area` / `shelf_level` 与随后的 `put_down_box` 相同）。同层也会发。拿不到当前位姿时不插中间点、直达目标，导航接收 3s 后再发 `adjust_pose`。

### PICK_COMPONENT_TO_SP

```json
{
  "cmd_type": "PICK_COMPONENT_TO_SP",
  "params": [
    {
      "box_initial_area": "component_car",
      "box_num": 0,
      "component_type": "black_screw",
      "target": [
        { "box_target_area": [0, 0, 0], "component_number": 10 },
        { "box_target_area": [0, 1, 0], "component_number": 10 }
      ]
    },
    {
      "box_initial_area": "component_car",
      "box_num": 1,
      "component_type": "black_screw",
      "target": [
        { "box_target_area": [0, 0, 0], "component_number": 10 },
        { "box_target_area": [0, 1, 0], "component_number": 10 }
      ]
    }
  ]
}
```

- `params` 为任务列表（也兼容旧版单个对象）
- `box_initial_area`：取件导航点，目前均为 `component_car`
- `box_num`：闪攀小车箱子位置，机器人前方 **左 0 / 右 1**
- `component_type`：该箱零件类型（一箱一种）
- `target`：播种墙目的地列表；`box_target_area` 为 `[货架编号, row, column]`
  - `编号 + column` → 放件导航点 `shelf{编号}_{column}`
  - `row` → `shelf_level`
- 零件类型：`black_screw`、`black_tube`、`black_square`、`black_joystick`、`black_fan`、`yellow_hinge`、`white_connector`、`wire_harness`
- 分拣成功后按 `programs/KAIAO/robot_config.json` → `kaiao_component.weight_kg` 的单件重量累计到对应货架格；后续从该格 `PICK_BOX_TO_SP` 时，重量达到 `heavy_box_threshold_kg` 则抓箱用 `pick_up_heavy_box`（仅 `area=shelf`），放箱用 `put_down_heavy_box`。AGV 上车箱视为 0kg，始终 `pick_up_box` + `put_down_box`。现场改重量后 `RESET_SYSTEM` 或重启生效。
- 抓箱后导航去放箱位：离架后退中间点调用 `adjust_pose`（area / shelf_level 与 `put_down_box` 相同；同层也会发）。拿不到当前位姿则直达目标，导航接收 3s 后再发 `adjust_pose`。

HTTP 立即返回受理：

```json
{
  "success": true,
  "code": 0,
  "action_type": "PICK_COMPONENT_TO_SP",
  "description": "",
  "message": "动作 PICK_COMPONENT_TO_SP 已受理，后台执行中"
}
```

完成后通过回调上报成功/失败。
