# WRC 项目功能清单

> 演示装配流程：WA2（robot_a）分拣搬箱 + WA1（robot_b）装配 + robot_c 拆垛放箱。  
> 由 ATC 改造：取消 PLC；`pick_box_to_sp` 由 robot_c 执行（无 area，一次向 P1/P2 各放一箱）。

---

## 项目结构

```
programs/WRC/
├── WRC.py               # 任务处理器主文件（WRCHandler）
├── constants.py         # WRC 专属常量
├── robot_config.json    # 含 robot_a / robot_b / robot_c
├── 功能清单.md
├── wrc_p*_slots.json    # 槽位状态持久化
└── plc_modbus.py        # 已不使用
```

---

## 接收的 HTTP 命令

| cmd_type | 说明 |
|---|---|
| `PROCESS_BEGINS` | 启动连续演示（robot_a + robot_b） |
| `PROCESS_PAUSED` / `RESUMED` / `ENDED` | 暂停 / 恢复 / 结束 |
| `MANUAL_RESET_COMPLETED` | robot_c 执行 `pick_box_to_sp`（无 area）→ P1=FULL |
| `TRANS_COMPONENT` | 单次启动 |
| `WRC_NEXT_STEP` | 预留 |

---

## 机器人分工

| 机器人 | 职责 |
|---|---|
| **robot_c** | 拆垛：`pick_box_to_sp`，一次向 P1、P2 各放一箱（不传 area） |
| **robot_a** | 分拣搬箱：抓放零件（Action）+ 空/满箱交换（Service） |
| **robot_b** | 装配：`assembly` / `continue_assembly` |

### robot_c（MANUAL_RESET 触发）

```
MANUAL_RESET_COMPLETED
  → Service pick_box_to_sp（无 area）
  → P1 = FULL
```

### robot_a / robot_b

与原先流程图一致（robot_a 不再负责拆垛）。

---

## 接口约定

| 类别 | 机器人 | 通道 | task | area |
|---|---|---|---|---|
| 拆垛 | robot_c | Service `/robot_task` | `pick_box_to_sp` | **不传** |
| 零件 | robot_a | Action | `pick_up/put_down_component_A/B` | `point_*` |
| 搬箱 | robot_a | Service | `pick_up_box` / `put_down_box` | `point_*` |
| 装配 | robot_b | Service | `assembly` / `continue_assembly` | 可空 |
